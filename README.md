# Game

Game ini merupakan sebuah game yang dikembangkan oleh tim developer bernama **KeyzForge**. Game yang kami bangun adalah game santai yang dapat dimainkan oleh tiga orang atau lebih.

Dalam game ini, para pemain dapat bermain bersama, bekerja sama, menyelesaikan berbagai tantangan, serta menikmati permainan dengan teman-teman. Kami berusaha membuat gameplay yang sederhana, menyenangkan, dan mudah dimainkan oleh semua orang.

## Fitur Utama

- Dapat dimainkan bersama teman.
- Mendukung tiga pemain atau lebih.
- Memiliki gameplay yang santai dan menyenangkan.
- Tersedia berbagai tantangan dan aktivitas.
- Akan terus mendapatkan pembaruan dan fitur baru.

## Tim Developer

Game ini dikembangkan oleh **KeyzForge**, sebuah tim developer yang berfokus untuk menciptakan game dan proyek digital yang kreatif serta menarik.
